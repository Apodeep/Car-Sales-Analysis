# Dataset

The raw car sales dataset used in this project is not included in the repository.

The dataset contains 23,906 car sales transactions covering 2022–2023, including transaction, customer, dealer, vehicle, pricing, and regional information.

The original dataset should only be redistributed when permitted by its source, licensing terms, and applicable privacy requirements.

To reproduce the analysis, obtain the dataset from its permitted source and use the expected CSV file as the input for the Python notebook.
